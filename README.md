# Data Visualization with Matplotlib and Seaborn

## Project Overview
This is my second Data Science project. In this project, I performed data visualization using Python libraries to understand and analyze the Tips dataset.

## Dataset
- Dataset Name: Tips Dataset
- Source: Seaborn Library
- The dataset contains restaurant bills, tips, customer size, day and meal time.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Visualizations

I created the following four visualizations:

1. **Histogram:** Shows the distribution of total restaurant bills.
2. **Box Plot:** Compares tip amounts across different days.
3. **Scatter Plot:** Shows the relationship between total bills and tips.
4. **Correlation Heatmap:** Displays correlations between numerical variables.

## Key Findings
- Most restaurant bills are concentrated between $10 and $20.
- Sunday has the highest median tip in this dataset.
- Total bill and tip have a positive relationship.
- Total bill and tip have a correlation of approximately 0.68.

## Project Output
The project includes a combined dashboard containing all four visualizations.

## Conclusion
This project helped me understand data visualization techniques and how to use Python libraries to explore and interpret data.
